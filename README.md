# 팀 업무 계획 웹앱 (V1)

Supabase Auth + 기존 Supabase 테이블을 사용하는 정적 웹앱입니다.
별도 빌드 없이 로컬 HTTP 서버에서 바로 실행할 수 있습니다.

## 실행

폴더에서 아래 중 하나를 실행하세요.

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## 포함 기능
- 이메일/비밀번호 로그인 (Supabase Auth)
- 전체 업무: 타임라인 / 개인별 보기
- 내 업무: 타임라인
- 검색: 업무명 / 프로젝트명 / 담당자 이름·닉네임
- 필터: 담당자 / 상태 / 프로젝트
- 프로젝트 행 펼치기 및 프로젝트 정보 수정
- 업무 우측 상세 패널 (배경 블러 없음)
- 권한에 따라 업무 수정/삭제 버튼 표시
- 프로젝트 생성: 누구나, 생성자 자동 오너
- 프로젝트 오너/관리자: 프로젝트 참여자 업무 생성 가능
- 참여자: 프로젝트 내 자기 업무 생성 가능
- NEW 배지: 생성 후 7일
- 2026년 9월 ~ 2027년 3월 고정 타임라인 + 오늘 표시선

## 배포
정적 호스팅(Vercel/Netlify/GitHub Pages 등)에 올릴 수 있습니다.
Supabase publishable key는 브라우저용 공개 키이므로 현재 구조에서 프론트에 포함되어 있습니다. 실제 보안은 Supabase RLS가 담당합니다.
